# 网页“文本输入框”定位结果

页面：https://baobaomi900901.github.io/xpath/#/iframe-shadow-form

结果：两个匹配，按用户“只有一个结果才入库”的条件，未调用 capture，element 元素库保持为空。

| 位置 | 表单 | 标签 | placeholder | input ID | 本次观察 ref |
| --- | --- | --- | --- | --- | --- |
| 左侧 | Ant Design | 文本输入框 | 请输入文本 | form-controls-ant-text | f1e41 |
| 右侧 | 原生 HTML | 文本输入框 | 请输入文本 | form-controls-native-text | f1e50 |

两个 input 均为 type=text、可见且未禁用，位于 iframe 内的 Open Shadow DOM。
标签核对：最近包含标签的祖先节点中，label 文本均为“文本输入框”。该 label 的 for=text 与实际 input ID 不一致，因此语义树只显示 placeholder“请输入文本”；结合 DOM 标签、元素属性和左右位置识别候选。

CLI 流程：browser list → observe web open → observe web details → web run-code（只读标签核对）→ observe web close。
observe web tree 可获取一次性语义树；需要后续 capture 时使用 observe web open 保留 session、snapshot 和 ref。
本次复用了已打开的精确目标页面。临时观察已关闭，页面保留；Runtime 当前元素库与开始时相同。
上述 ref 仅对应本次观察快照，关闭观察后不能用于下一次入库。选定一侧后需重新观察。
