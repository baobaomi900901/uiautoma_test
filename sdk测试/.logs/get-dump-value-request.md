## 期望解决的问题

希望从指定 Win32 容器元素批量获取下级控件可读取的数据，用于列表、表格或其他数据区域的测试与采集，减少逐个遍历元素并读取内容的脚本工作。

以上为本项目拟议用途，并非已验证的影刀内部行为；目前没有影刀真实返回样例或实现代码。不要把关于其递归方式、过滤方式或底层实现的猜测当作兼容性要求。

## 请开发明确的合同

- 提取范围：是否包含当前元素、仅直属子元素还是递归后代，以及结果顺序。
- 可用数据的定义：支持哪些控件和数据来源；不支持的控件如何处理。不要求读取应用私有内存。
- 两个过滤参数的含义及匹配规则，None/空字符串行为，两项同时提供时如何组合。
- `state` 的数值含义、错误处理方式及其与现有 SDK 异常风格的关系。
- `class`、`object`、`content` 的取值来源；`attributes` 的合法结构和键值类型。
- 无匹配、空内容、不可访问元素及过期元素的结果；遍历的耗时/数量边界。

接口名称和返回结构可以结合现有 SDK 风格确定，但请在实现前明确上述关键行为，提供可复现的调用示例。
