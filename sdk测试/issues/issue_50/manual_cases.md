建议分轮执行：先 A1～A2，再 B1/B3/B4/B7/B8，再 C/D，最后 Web 和开发协助项。

## 观察及反馈

从 preflight 获取 App PID（重启 App 后需重新获取），例如：

```powershell

```

PID 仅为示例。观察开始后切回 App 操作；初始终端切焦点属于准备动作。
观察器每 50ms 读取前台窗口、原生菜单标志、App 可见/最小化/置顶状态，只记录变化，
不激活窗口、不发按键；可能漏过更短事件。标题会存入本地记录，分享前可检查内容。
`Ctrl+C` 可提前结束并保存。观察不能证明元素匹配或按钮禁用正确，仍需人工判断。

可直接发反馈：`A1 PASS；目标=靶场右键菜单；源菜单项=…；相似项=…；实际=…`。
失败请给出前台程序、菜单类型、入口/快捷键、实际错误和录屏或观察文件名。


观察、版本、自动回归保存在 JSON；人工结果追加到 JSONL，重复操作保留历史。
未测项保持 NOT_RUN；本工具不修改 GitHub，不自动勾选 Issue、不自动判定整单通过。

## B 组入口矩阵

B1～B6 各自覆盖以下七个入口，逐入口记录结果：`new` 新捕获、`recapture` 重新捕获、
`similar` 相似捕获、`image-new` 图像捕获、`image-recapture` 图像重新捕获、
`anchor-add` 添加锚点、`anchor-reselect` 重新选择锚点。
只对产品实际支持的快捷键执行 B2，不臆造快捷键；不适用项说明理由，不能默记通过。
图像入口按屏幕提示框选；元素/相似/锚点入口按提示点选。每轮只完成当前入口。

### A1 Win 右键菜单动态相似捕获

步骤：打开目标右键菜单，捕获并保存一个菜单项；关闭菜单；在 App 选中该库项，
点击相似捕获或 F5；确认已经进入捕获后，再回目标打开右键菜单，按提示选择另一个同类项。
预期：菜单未展开时也能进入捕获；选择后生成有效相似规则并保存，可校验匹配同类项。
记录源项、样本项和保存结果。若没有合适同类菜单项，标记 BLOCKED 并说明目标。

### A2 Win 顶部菜单与下拉菜单

步骤：分别对顶部菜单项、下拉菜单项执行 A1 的“先保存→关闭菜单→启动相似捕获→再展开→选择同类项”。
预期：两种菜单均不因启动时不存在而阻止捕获。分别记录 variant=top-menu/dropdown。

### A3 Web 动态菜单

步骤：在自有页面保存动态菜单项，关闭菜单，启动相似捕获，再展开并选择同类项。
预期：可生成并保存有效规则；分别记录浏览器、页面 URL、源项和样本项。
普通 DOM 菜单不作为原生菜单保护证据。

### A4 Web 可见但未激活

步骤：浏览器与另一程序并排，保持目标可见；启动 Web 捕获后让另一程序拥有焦点，
按捕获提示直接点选浏览器目标。记录点选前的前台窗口及保存结果。
预期：不单纯因为浏览器在捕获/保存时非前台拒绝有效目标。仍需通过浏览器身份和窗口归属检查。

### A5 静态相似元素回归

步骤：分别保存 Win、Web 列表或表格中的一个静态元素，选择同类元素执行相似捕获，保存后校验。
预期：静态相似规则生成、匹配及保存正常。variant=win/web，记录目标列表与预期匹配范围。

### A6 无效相似样本

步骤：从已知列表项启动相似捕获，选择明显不属于同类结构的控件，例如列表外按钮。
预期：明确报错，不保存成无约束或错误范围的相似规则；原有记录保持可用。
记录所选样本及错误文案，不能把“任意目标被接受”算成功。

### A7 保存与复用

步骤：完成 A1/A3/A5 的相似捕获后记下预期匹配项，切换到其他测试库再重新打开本库；
恢复相应页面或展开菜单，校验刚保存的相似规则。
预期：规则可加载，匹配范围符合预期。至少分别记录 Win 与 Web。

### B1 App 前台启动捕获

步骤：逐入口准备源对象，将 App 放到前台，点击捕获入口；观察进入捕获时的窗口和焦点。
预期：App 最小化，外部目标程序获得操作焦点。然后完成或取消以回到空闲。
按七入口矩阵分别记录。

### B2 目标在前台时快捷键启动

步骤：App 预先选择测试对象，切到外部目标，展开适用的原生菜单；使用产品支持的快捷键启动。
预期：不先激活 App，不破坏已打开原生菜单。记录具体快捷键、入口及菜单类型。
不支持快捷键的入口记录不适用原因。

### B3 普通捕获成功恢复

步骤：保证没有原生菜单，逐入口启动并成功完成一次捕获/框选/锚点选择。
预期：完成后 App 恢复到前台并获得焦点，保存结果正确，入口恢复可用。

### B4 普通 Esc 取消

步骤：逐入口启动捕获，在外部目标程序中按一次 Esc。
预期：捕获结束、App 恢复，后续操作可用；不出现重复恢复或残留忙碌。

### B5 原生菜单保护恢复

步骤：使用菜单在收尾时仍保持打开的场景，逐适用入口完成捕获或取消，同时观察菜单与前台程序。
预期：App 显示在前面但不主动抢走目标焦点，原生菜单不因恢复被关闭。
若菜单在收尾前已关闭，此次不覆盖菜单保护，记录并另找可保持菜单的场景。

### B6 临时置顶撤销

步骤：接 B5；分别点击其他窗口、按键、切换窗口、开始下一轮捕获，并在各动作后继续观察数秒。
预期：App 不持续置顶、不延迟抢焦点；新操作正常。可用观察器辅助记录 topmost 变化。

### B7 原生菜单元素校验

步骤：App 选中已保存菜单项，切回目标展开原生菜单，按 F6 校验。
预期：不会因重复激活窗口而关闭菜单，按目标实际状态完成校验；记录校验结果和菜单变化。

### B8 启动后焦点回归

步骤：正常启动 App，切到靶场或编辑器持续输入/操作约 10 秒。
预期：App 不反复抢前台；记录前台程序变化。观察器可在 App 启动完成后启动，观察其后行为。

### C1 App 内 Esc

步骤：启动捕获，从任务栏切回 App，在 App 内按 Esc。
预期：捕获正确收尾，窗口只恢复一次，不重复弹回；下一轮可正常开始。

### C2 重复 Esc

步骤：启动捕获，快速连续按 Esc 三次，之后切换窗口并等待数秒。
预期：不重复收尾、不出现异常状态或延迟弹回。记录按键顺序。

### C3 取消后立即重试

步骤：启动后取消，取消完成后立即再次启动；分别针对相似捕获和图像重新捕获执行，重复三轮。
预期：旧任务不恢复窗口、不停止新捕获；新一轮可完成或正常取消。
variant=similar/image-recapture，记录是否存在时序性失败。

### C4 停止校验的延时恢复

步骤：启动一次可成功的校验，在成功后的三秒等待阶段切回 App 点停止，再立即操作其他窗口。
预期：剩余等待时间结束后 App 不再次弹回。若未赶上等待窗口，记本次未覆盖并重新执行一次。

### C5 未点选即取消

步骤：记录源元素数据及库项数量；分别启动新捕获、重新捕获、相似捕获，未点选时取消。
预期：不新增或覆盖元素，原数据正常。variant=new/recapture/similar。
已完成落盘后的取消不要求回滚，不使用该情形验证本项。

### C6 取消失败与重试（开发协助）

步骤：由开发提供可控注入，让 Provider 取消请求异常/业务失败或跟随停止失败；启动捕获后取消，
记录错误；开发恢复服务/注入，再执行停止重试。
预期：首次显示取消未完成而非完成，保留重试状态；后续成功后正常收尾。
未提供注入入口时记录 BLOCKED；不要通过随意杀进程代替。分别记录各故障类型。

### C7 Debug 停止失败后 Esc 重试（开发协助）

步骤：开发分别注入 Provider 请求异常和业务失败；捕获中点击 Debug 停止；记录会话仍在进行的状态。
恢复服务后在 App 内按 Esc。
预期：首次不提前结束会话/释放窗口租约，Esc 重新发送取消并成功后只恢复一次。
需开发日志证明请求重发与租约时机，界面观察不足时保留未测部分。

### C8 Debug 停止失败后按钮重试（开发协助）

步骤：按 C7 制造失败，恢复服务后再次点击 Debug 停止按钮，分别覆盖请求异常和业务失败。
预期：可以重新请求取消，成功后结束会话、释放租约，无永久忙碌；需开发日志辅助。

### D1 捕获期间禁止校验

步骤：逐捕获入口启动，在捕获及保存收尾期间检查元素/图像校验按钮并尝试 F6。
预期：两种校验不能启动，原捕获不中断；特别记录短暂入库收尾阶段是否实际覆盖。

### D2 校验期间禁止捕获

步骤：分别启动元素校验、图像校验；期间检查新捕获、重新捕获、相似捕获、图像捕获、
图像重新捕获、添加/重新选择锚点入口。
预期：所有冲突入口不能启动，校验保持正常；分别记录两种校验模式。

### D3 快捷键不能绕过互斥

步骤：在 D1/D2 的忙碌状态分别尝试 F4、F5、F6，并对照对应按钮状态。
预期：快捷键和按钮遵守同样互斥，不启动第二个冲突任务；不要只看按钮灰色就判通过。

### D4 切换列表不能绕过互斥

步骤：捕获或校验忙碌时，切换元素列表/图像列表，尝试该列表的冲突入口。
预期：列表切换不解除互斥、不并发启动任务。若忙碌时不允许切换，记录实际设计。

### D5 收尾后恢复可用

步骤：分别在成功、正常取消、可复现错误收尾后检查按钮与 F4/F5/F6，执行一次符合条件的新操作。
预期：恢复可用，无永久忙碌；没有选中对象等正常禁用原因需排除。

### E1 快捷键提示

步骤：将鼠标依次悬停重新捕获、相似捕获、校验按钮。
预期：提示分别显示 F4、F5、F6，与实际功能对应。

### E2 捕获按钮简化提示

步骤：悬停“捕获元素”按钮并等待提示出现，记录提示文字或截图。
预期：不再显示原先过长的 hover 提示；若无法确认旧文案差异，反馈当前全文供比对。
